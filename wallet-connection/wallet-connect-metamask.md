### Wallet Connection via MetaMask

**Objective**  
Verify correct wallet connection flow using MetaMask.

**Preconditions**
- MetaMask installed and unlocked
- Supported network selected

**Steps**
1. Open dApp
2. Click "Connect Wallet"
3. Select MetaMask
4. Approve connection in wallet

**Expected Result**
- Wallet connects successfully
- Wallet address displayed in UI
- No duplicate wallet popups
- No console errors

**Risk if broken**
User may believe wallet is connected while it is not, leading to failed transactions.
